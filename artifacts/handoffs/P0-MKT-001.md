## 1. Executive summary

1. The Odds API is the only self-serve, documented source that gives timestamped, by-book NFL snapshots — live and historical (from 2020-06-06, 10-min snapshots; 5-min from Sept 2022). Paid tiers start at $30/mo (20K credits); historical calls cost 10× normal credits and are paid-only. US-book coverage in 2020 is explicitly described as "limited."
2. Pre-2020 by-book, timestamped lines do not exist in any accessible public source. Pre-2020 you get at best one open + one close + one ML per game (SBR, 2007–2021) or one close spread/total per game (PFR / Covers-SportsOddsHistory, 1978+).
3. Sportsbook Reviews Online (SBR) archive is frozen: 2007-08 through 2021-22, "will not be updated." Columns: Date, Rot, VH, Team, Q1–Q4, Final, Open, Close, ML, 2H. No book identity, no legend, no xlsx link visible on the live pages (HTML tables only; xlsx UNVERIFIED).
4. Pro-Football-Reference "Vegas Lines" exist per team-season (`/teams/{abbr}/{year}_lines.htm`) with Spread + Over/Under + ATS result; PFR credits "Warren Repole and Sports Odds History." No ML, no open, no book. ToS forbids automated access without written permission and forbids building derivative datasets; a boxscore fetch returned HTTP 403 during this research.
5. Covers.com's Sports Odds History (formerly sportsoddshistory.com) is NOT independent of PFR — its page states "Odds from 1978 - present courtesy of Pro-Football-Reference.com and are the closing odds." Only spread + total, no ML, no download.
6. Kaggle `spreadspoke_scores` could not be verified live (client-rendered; API blocked). Column list/provenance UNVERIFIED.
7. Historical betting splits (ticket % / handle %) are effectively unavailable. Action Network ToS bars scrapers; VSiN publishes DraftKings splits only as articles/data.vsin.com with no archive; SharpAPI's `/splits/history` retains only 48 hours ($229/mo). Sportradar Betting Splits is enterprise.
8. Book identity for 2026: ESPN BET ceased Dec 1 2025 and became theScore Bet (PENN); The Odds API still uses key `espnbet` labelled "theScore Bet (formerly ESPN Bet)". Caesars = `williamhill_us`, Fanatics = `fanatics` (both paid-only in The Odds API). bet365 US is live in ~16–17 states but has no US key in The Odds API. Circa is in no self-serve aggregator except SportsGameOdds Pro ($299/mo); Pinnacle closed its public API July 2025, The Odds API serves `pinnacle` (EU region) "from public website which may incur a delay."
9. Recommended canonical + validation pair for 2010–2025 closers: SBR (2010–2021, has open/close/ML) as canonical where it exists, validated against PFR team lines pages (manual/low-rate, personal use) — and for 2020–2025 The Odds API historical closing snapshot (DraftKings/FanDuel/Pinnacle) as the independent check. No published quantification of SBR-vs-PFR discrepancies was found (UNVERIFIED magnitude; must be computed in-project).
10. Minimal cost: historical backfill ≈ one or two months of The Odds API START 100K ($59/mo); ongoing weekly snapshots fit in START 20K ($30/mo). Everything else in the historical stack is free.

## 3. Per-source details

### The Odds API — historical endpoints
- Endpoints: `GET /v4/historical/sports/{sport}/odds` (snapshot "closest ... equal to or earlier than the provided `date`"), `/historical/sports/{sport}/events`, `/historical/sports/{sport}/events/{eventId}/odds`, `/historical/.../markets`.
- NFL earliest timestamp `2020-06-06T10:05:00Z`. 10-min snapshots until Sept 2022, then 5-min. Additional markets from `2023-05-03T05:30:00Z`.
- Caveats quoted: "note coverage of US bookmakers was limited in 2020"; "Historical data will only be available from the time that coverage is added for a sport, bookmaker or market"; before 2022-09-18 only decimal odds were captured and American odds "may include small rounding errors."
- Cost: `10 × markets × regions` per snapshot call; empty responses free. Response carries `timestamp`, `previous_timestamp`, `next_timestamp`. Sport key `americanfootball_nfl`.

### The Odds API — live
- Plans: Starter free 500 credits/mo (no historical); START 20K $30; START 100K $59; START 5M $119; START 15M $249. Cost per `/odds` call = markets × regions; each 10 bookmakers in `bookmakers=` = 1 region.
- US (`us`): draftkings, fanduel, betmgm, betrivers, williamhill_us (Caesars, paid only), fanatics (paid only), bovada, betonlineag, betus, lowvig, mybookieag. `us2`: espnbet (theScore Bet), hardrockbet, ballybet, betparx, fliff, betanysports→"BetAnything", rebet (paid). `us_ex`: kalshi, polymarket, novig, prophetx, betopenly. `eu`: pinnacle. No Circa; no US bet365.
- Alternate spreads/totals via event-odds endpoint; props US/AU only. Rate limit: 429 with advice to space requests; no numeric limit published. Bookmakers can drop out "a few hours to a few days."
- Key point: paid historical access records every 5 min anyway, so missed live snapshots can be backfilled retroactively.

### Sportsbook Reviews Online
- Index says archives cover "moneylines, 2nd half lines, opening and closing point spreads and totals" and "will not be updated." Regular season 2007-08…2021-22 (15), preseason 2007-08…2021-22 minus 2020-21.
- Live pages are HTML tables (page date 2023-04-08), two rows per game (V then H). Verified rows: `905 | 451 | V | GreenBay | … | 10 | 46 | 46.5 | 140 | 23` / `905 | 452 | H | Chicago | … | 3 | 3.5 | 3 | -160 | 3`. Parsing rule (project must implement, not documented by SBR): the favorite's row carries the spread in Open/Close/2H, the dog's row carries the total; `pk` = pick'em; Date is `MDD` without year; Rot numbers present. No book named, no legend, no xlsx link found (old `.xlsx` URLs redirect to the homepage).

### Pro-Football-Reference
- Team-season "Vegas Lines" table: G#, Opp, Spread, Over/Under, Result, vs. Line, OU Result. Source: "Historical Vegas line data comes from Warren Repole and Sports Odds History."
- ToS: no "automated means to access or use the Site" without "express written permission"; bars training AI or building "a material substitute"; custom data minimum $1,000.

### Covers.com Sports Odds History
- sportsoddshistory.com now 302-redirects to covers.com. Season pages: per-week tables with Day, Date, Time (ET), @/N marker, Favorite, Score, Spread (W/L/P + line), Underdog, Over/Under (O/U/P + total), Notes. No moneylines.
- Stated: "Odds from 1952 - 1977 courtesy of Newspapers.com and are from the night prior to the game. Odds from 1978 - present courtesy of Pro-Football-Reference.com and are the closing odds." Terms: "please reference and link to our site"; Genius Sports copyright.
- Covers' live odds page: "Opening odds are from a reputable international sportsbook with the highest limits" (unnamed); "Consensus numbers are powered by Covers Contests" (contest picks, not handle).

### Kaggle NFL scores and betting data (tobycrabtree / @spreadspoke)
- Page client-rendered; Kaggle API blocked. Columns, years, license, update status UNVERIFIED. Secondary blog says only "the lines came from Las Vegas sports books." Treat as tertiary.

### aussportsbetting.com
- "NFL: from 2006"; single `nfl.xlsx`. Odds source and open/close status in the workbook's Notes sheet (could not download; Pinnacle attribution UNVERIFIED). Terms: personal use only, no re-hosting, "may contain errors."

### 2026 US book identity
- ESPN BET → theScore Bet on 2025-12-01 (PENN/ESPN terminated 2025-11-06). Canonical id `thescore_bet` with alias `espnbet` (The Odds API key) and `espn_bet` for Nov 2023–Nov 2025 rows.
- Fanatics Sportsbook: 23 states + DC (~Mar 2026). Odds API key `fanatics` (paid).
- bet365 US: ~16–17 states; no US feed in The Odds API.
- Caesars `williamhill_us`; Hard Rock Bet `hardrockbet`; Bally Bet `ballybet`; BetRivers `betrivers`; Fliff `fliff`; exchanges `kalshi`/`polymarket`/`novig`/`prophetx`. Pinnacle `pinnacle` (region `eu`); Circa no key.

### Independence map
- PFR ← Warren Repole + SportsOddsHistory; Covers/SOH (1978+) ← PFR. One lineage. SBR (2007–2021) separate lineage (unnamed book). The Odds API (2020+) third, by-book. aussportsbetting (2006+) fourth, provenance UNVERIFIED. nfldata closing_lines (2006–2018) provenance not stated.
- Structural differences to expect: SBR single unnamed book's close vs PFR "consensus" close; half-point and pick'em conventions; SBR two-row layout; neutral-site games; SBR Date lacks year; Odds API 2020 US coverage thin.

## 4. Recommended minimal stack

(i) Historical backtest (2010–2025)
1. SBR HTML tables 2010-11…2021-22 → parse Open/Close/ML/2H (free).
2. The Odds API historical, 2020 preseason → 2025: one snapshot per kickoff slot for "close" (≈100 snapshots/season) plus one per Tuesday for "open" (≈20/season); `markets=h2h,spreads,totals`, `regions=us,eu` → 60 credits/snapshot → ≈7,200 credits/season → ≈43K credits for 6 seasons. One month of START 100K ($59).
3. PFR team lines (manual spot checks only) / Covers-SOH as validation for the closing spread+total.
4. nflverse schedules for results/ids; aussportsbetting xlsx optional cross-check.
Total ≈ $59 one-time.

(ii) Weekly live snapshots, 2026 onward
- The Odds API START 20K ($30/mo). Snapshot schedule: Tue AM (open), daily noon, T-60 min before each kickoff slot; `markets=h2h,spreads,totals`, `regions=us,us2,eu` = 9 credits/call → ~15 calls/week ≈ 135 credits/week; add alternate spreads/totals via event endpoint ≈ +300/month. Missed snapshots backfillable from history.
- Optional SharpAPI Pro $229/mo for splits — recommended no initially.

## 5. Limitations the project must document
1. No reliable historical betting splits; any splits feature starts from collection date, 3 books max.
2. Pre-2020: no timestamps, no book identity; "close" means one unnamed book (SBR) or PFR consensus. Openers only via SBR (2007–2021), nfldata initial_lines (2021), The Odds API (2020+).
3. PFR cannot be bulk-scraped; Covers/SOH derives from PFR, so they are not two independent validations.
4. The Odds API 2020 US coverage thin; pre-2022-09-18 American odds converted from decimals; bookmakers drop out; Pinnacle delayed.
5. Circa and bet365-US absent from the primary feed; Pinnacle is a sharp reference, not a bettable US book.
6. Book identifiers change over time; store `book_id` + display name at time + validity dates.
7. Kaggle spreadspoke provenance, aussportsbetting odds source, SBR xlsx availability UNVERIFIED.
8. Prediction markets (Kalshi, Polymarket, Novig) appear as `us_ex`; schema decision needed.
